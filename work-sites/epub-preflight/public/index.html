EPUB 기본 구조 검사기

전자책을 제출하기 전 파일 자체에 기초 구조가 있는지 확인할 때 EPUB 파일을 선택하면 내부 이름 기준 검사 결과를 확인할 수 있습니다. 입력한 파일은 브라우저에서 처리하며 서버에 저장하지 않습니다.

검사 한계

EPUBCheck 수준의 유효성 검증, 목차·이미지·본문 내용 검사는 제공하지 않습니다. 결과는 참고용이므로 원본과 해당 분야의 검증 자료를 직접 확인하세요. 관련 법령상 운영자의 면책 불가능한 책임까지 부인하지 않습니다.
