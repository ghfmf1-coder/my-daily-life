# 관리자 인증 및 동기화 (2026-10-14)

- 기존 콘솔: **v1.2 기능 유지**, 사이트 목록 자동 동기화 및 Cloudflare 배포 확인 유지.
- 인증: 하루한칸 Supabase Auth 계정으로 로그인한 뒤, `toolbox_admin_members` RLS 허용 계정인지 확인.
- 저장: `toolbox_admin_workspaces` 테이블에 계정별 JSON 문서, 버전, 갱신 시각 저장. 브라우저에도 저장하며 이전 기록을 자동 병합하고 초기 로컬 백업을 별도로 유지.
- 충돌: 서버 버전과 다르면 수정을 거부하고 로컬 사본을 유지. 사용자는 다시 동기화/새로고침 후 복구해야 함.
- 보안 한계: 정적 HTML/JS와 공개 사이트 카탈로그는 여전히 인터넷에서 접근 가능함. **Cloudflare Access 정책으로 도메인 전체를 보호하는 별도 설정이 필요**함. 인증 및 RLS는 운영 데이터만 보호함.
- 공개 브라우저 설정의 `sb_publishable_*` 키는 공개 가능. service_role 비밀키는 사용하지 않음.
- 현재 초기 관리자 허용 계정은 Supabase 기존 Auth 계정 1개로 한정됨. 새로 가입한 계정은 자동 허용되지 않음.
- Google Search Console 색인 상태는 API OAuth 연결 전까지 '미확인'으로 유지하며 사이트 배포/접속 확인과 구분함.
