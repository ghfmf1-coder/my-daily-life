서비스 이용약관

작은 도구함(Small Toolbox)은 abreda.com에서 무료 브라우저 도구를 찾고 사용할 수 있도록 연결합니다. 이 약관은 메인 도구 목록 서비스 이용에 적용됩니다.

1. 서비스 이용

이용자는 법령을 준수하고 서비스를 정상적인 목적에 사용할 수 있습니다. 서비스 취약점 악용, 다른 사람의 권리 침해, 과도한 자동 요청, 악성 파일 유포 등은 허용하지 않습니다.

2. 독립적인 도구와 외부 링크

목록에 소개된 웹 도구는 각각 고유한 기능·데이터 저장 방식을 가질 수 있습니다. 외부 도메인과 플랫폼으로 이동하는 경우 해당 서비스의 약관과 개인정보처리방침도 확인해 주세요.

3. 콘텐츠와 이용자의 책임

이용자가 입력·제작한 파일, 원고 및 기타 콘텐츠의 권리는 원칙적으로 해당 권리자에게 있습니다. 이용자는 관련 법령과 제3자의 권리를 준수할 책임이 있습니다. 공개 GitHub Issues에 개인정보 또는 미공개 원고를 올리지 마세요.

4. 도구 결과의 한계

파일 처리, 원고 분석, 연재 계획 등의 결과는 참고용이며 무결성·적합성·완전성을 보장하지 않습니다. 중요한 파일은 원본 백업 후 결과를 독립적으로 확인해 주세요. 본 조항은 법령상 배제할 수 없는 운영자의 책임을 면제하지 않습니다.

5. 서비스 변경 및 장애

보안, 유지보수, 법령 준수, 품질 개선 등의 사유로 기능을 변경·중단할 수 있습니다. 가능한 범위에서 주요 변경 사항을 사이트에 안내합니다.
