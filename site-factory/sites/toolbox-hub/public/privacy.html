개인정보처리방침

작은 도구함(Small Toolbox)은 abreda.com에서 제공하는 무료 도구 목록 서비스입니다. 이 문서는 이 도구 목록 사이트에서 개인정보를 어떻게 처리하는지 설명합니다. 연결된 개별 서비스의 개인정보 처리는 각 서비스 안내를 함께 확인해야 합니다.

1. 운영자와 문의처

운영 주체: 작은 도구함 개인 운영자(대한민국)
개인정보 관련 문의: ghfmf1@gmail.com

2. 수집하거나 처리할 수 있는 정보

  • 사이트 접속 정보: 사이트 제공·보안·장애 대응을 위해 호스팅 제공자인 Cloudflare가 IP 주소, 접속 시각, 요청 URL, 브라우저·기기 정보 등 기술적 요청 정보를 처리할 수 있습니다.
  • 직접 전달하는 정보: 이메일 또는 GitHub Issues로 문의하면 보내 주신 이메일 주소, 메시지와 첨부 자료가 해당 서비스와 운영자에게 전달됩니다. 공개 GitHub Issues에 입력한 내용은 다른 사용자에게 보일 수 있습니다.
  • 도구 입력 내용: 이 도구 목록 페이지 자체는 계정을 만들거나 CSV 파일·원고를 업로드받지 않습니다. 연결된 CSV 병합기와 원고 분석기의 처리는 해당 도구의 안내를 따릅니다.

3. 이용 목적 및 제공·위탁

사이트 운영, 접속 안정성·보안 유지, 문의 처리와 오류 수정에 필요한 범위에서 정보를 사용합니다. 웹사이트 전송 및 보호를 위해 Cloudflare의 호스팅·보안 인프라를 이용하며, 이메일·GitHub 문의는 각 제공업체의 환경에서 처리됩니다. 사이트 운영에 필요한 범위를 넘어 개인정보를 판매하지 않습니다.

4. Google Ads API 및 Google 계정 정보

작은 도구함 운영자는 신규 도구 수요를 연구하기 위해 자신의 Google Ads 계정에 OAuth로 접근할 수 있습니다. 이 경우 운영자가 승인한 범위에서 키워드 아이디어, 검색량 통계 및 API 연결에 필요한 광고 계정 정보를 조회하고 내부 기획·평가에만 사용합니다. 일반 웹사이트 방문자의 Google 계정 연결이나 Google Ads 정보 제공을 요구하지 않습니다. OAuth 권한은 Google 계정의 연결된 앱 관리에서 해제할 수 있습니다. 연동 기능이 실제 도입되면 접근 범위와 보관 방식에 관한 내용을 추가로 반영합니다.

5. 쿠키와 브라우저 저장소

이 도구 목록 페이지는 자체 회원가입이나 개인화 광고 쿠키를 요구하지 않습니다. 다만 Cloudflare가 보안·봇 방어를 위해 필수 기술적 쿠키를 사용할 수 있습니다. 연결된 개별 도구의 로그인 및 로컬 저장 기능은 별도로 동작합니다.

6. 보관 및 삭제

문의 내용은 문의 처리와 관련 분쟁 대응에 필요한 기간 보관 후 불필요해지면 삭제합니다. 기술적 접속 기록은 호스팅 제공업체의 보안·보관 정책 및 적용 법령에 따라 처리됩니다. 이메일로 열람·정정·삭제 등 개인정보 관련 요청을 할 수 있으며, 법령상 보관 의무 등 정당한 제한이 있으면 그 사유를 안내합니다.

7. 연결된 외부 서비스 및 국외 처리

홈페이지는 Cloudflare 인프라를 이용하며, 이메일 제공업체 및 GitHub와 같은 외부 서비스는 국외에서 데이터를 처리할 수 있습니다. 메인 사이트에서 연결하는 하루한칸처럼 계정이 필요한 서비스는 별도 방침이 적용될 수 있습니다.

8. 방침 변경

서비스, 분석 도구, 광고 또는 정보 처리 방식이 바뀌면 이 방침을 실제 운영 내용에 맞게 업데이트하고 개정일을 표시합니다.

방문 통계: 접속 시 페이지뷰와 브라우저 탭별 일일 세션 여부를 Supabase에 집계합니다. 통계 DB에는 사이트 식별자·한국 기준 날짜·집계 수만 보관하며 IP 주소·쿠키·기기 지문·업로드 파일·원고 내용은 저장하지 않습니다. 차단 프로그램과 자동 방문으로 수치가 달라질 수 있습니다.
