Text to Columns Converter

Split pasted lines by commas, tabs or whitespace into tab-separated columns for spreadsheets. Quoted CSV fields are recognized in comma mode.

How to use the result

Comma mode handles quoted commas and doubled quotes within each line, but rejects multiline quoted CSV fields. Tab mode preserves empty cells; whitespace mode treats runs of spaces as one separator. Copy the resulting TSV into a spreadsheet. Import sensitive identifiers as text to avoid automatic date conversion and leading-zero loss.
