CSV 맞춤 병합기

열 이름이 다른 CSV도 한 번에 합치세요. 열 이름 자동 통일 → 열 연결 직접 확인 → 중복 제거 → 다운로드까지 한 화면에서 처리합니다.

파일 서버 전송 없음 · 회원가입 없음

1. CSV 파일 불러오기

최대 10개 파일, 파일당 8MB, 전체 20MB. 첫 행은 열 이름으로 인식합니다. CSV·TSV·세미콜론 구분 파일을 지원합니다.

파일을 선택하거나 예제를 눌러 시작하세요.

2. 업로드 파일 확인

원본 파일은 변형되지 않습니다. 열 매핑은 결과 CSV에만 적용됩니다.

3. 열 이름 매핑

예를 들어 ‘고객명’과 ‘성명’을 모두 ‘이름’ 열로 연결합니다. 자동 제안을 원하는 대로 변경하거나, 열을 제외할 수 있습니다.

중복 제거 설정

선택한 열의 값이 비어 있다면 그 행은 중복 제거 대상에서 제외됩니다. 여러 열을 조합한 중복 판별은 아직 지원하지 않습니다.

4. 결과 확인 및 다운로드

다운로드는 UTF-8(BOM 포함) CSV로 저장됩니다. 결과 미리보기는 처음 20행만 표시합니다.

사용 방법과 주의사항

열 구조가 다른 CSV 파일을 어떻게 병합하나요?

여러 CSV를 선택하면 제목행을 읽고 ‘이름/성명/고객명’, ‘휴대폰/연락처’ 같은 흔한 열 이름을 자동 매칭합니다. 결과 열 연결을 확인한 다음 병합을 실행하세요.

기존 엑셀 파일(.xlsx)도 올릴 수 있나요?

현재는 CSV·TSV 형식만 지원합니다. 엑셀의 ‘다른 이름으로 저장 → CSV UTF-8’ 기능으로 내보낸 뒤 사용할 수 있습니다.

개인정보가 서버로 전송되나요?

아니요. 파일 파싱과 병합 및 다운로드는 브라우저 안에서만 처리합니다. 다만 공유 컴퓨터에서 작업할 때는 다운로드한 CSV 파일의 보관에 주의하세요.

병합 결과를 그대로 믿어도 되나요?

병합 기준과 중복 제거 결과를 검토하세요. 연락처 형식, 날짜, 숫자의 의미를 자동 판단하거나 검증하지 않습니다.

안내: 이 도구의 분석·변환 결과는 참고용이며 최종 확인과 이용 판단은 사용자가 해야 합니다. 관련 법령상 배제할 수 없는 운영자의 책임까지 면제하지 않습니다.
