사용 방법 및 주의사항

선택한 원본 파일을 직접 수정하지 않고 새 이름으로 복사한 ZIP을 생성합니다. 이름 변경 후 충돌을 미리 검사합니다. ZIP 해제 시 운영체제의 파일명 제한은 다를 수 있습니다.

회원가입 없이 사용하며 입력한 파일 내용은 서버에 업로드하지 않습니다. 방문 집계 시에도 파일 내용은 수집하지 않습니다.
