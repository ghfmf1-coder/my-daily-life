사용법과 처리 한계

라벨 면적과 A4 인쇄 가능 영역을 계산해 시트를 만듭니다. 출력 장치의 비인쇄 영역 때문에 끝부분이 잘릴 수 있으므로 미리보기로 확인하세요. QR코드 생성은 지원하지 않습니다.

입력 파일과 내용은 브라우저에서 처리합니다. 서버로 파일을 보내지 않습니다. 방문 통계에는 파일 내용이 포함되지 않습니다.
