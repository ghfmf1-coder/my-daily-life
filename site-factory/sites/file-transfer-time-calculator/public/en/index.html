File Transfer Time Calculator

Calculate theoretical file transfer time from a file size in MB, GB, MiB or GiB and a measured upload or download speed in megabits per second.

How to use the result

Choose decimal MB or GB when those are the units reported, or binary MiB or GiB where appropriate. Use measured upload speed for uploads, not the advertised download rate. The result assumes a constant effective throughput with no interruptions or protocol overhead. Real transfers may take longer.
