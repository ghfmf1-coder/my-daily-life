암호화된 PDF나 손상된 파일은 처리하지 못할 수 있습니다. 원본은 변경하지 않습니다.

사용 방법 및 주의사항

실제 PDF 페이지 내용은 브라우저 메모리에서만 처리합니다. 목록의 원본 페이지 번호를 기준으로 재배치합니다. 암호 해제, PDF/OCR 텍스트 편집, 서명 보존은 제공하지 않으며 PDF 라이브러리 파일 로드 시 외부 CDN 연결이 필요합니다.

회원가입 없이 사용하며 입력한 파일 내용은 서버에 업로드하지 않습니다. 방문 집계 시에도 파일 내용은 수집하지 않습니다.
