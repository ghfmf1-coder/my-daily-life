    이 도구로 해결하는 문제

    영상보다 자막이 늦거나 빠를 때 전체 시간을 같은 간격으로 이동합니다.

    23.976fps 자막을 25fps 영상에 맞추는 등 프레임레이트 차이로 서서히 어긋나는 싱크를 조정합니다.

    SRT와 WebVTT 파일을 상호 변환하고, 자막 간 겹침·역순·빈 내용·잘못된 길이를 확인합니다.

    자주 묻는 질문

    영상 파일도 업로드해야 하나요?

    아니요. 자막 파일만 필요합니다. 영상의 실제 음성을 분석하는 자동 싱크 맞춤 기능은 제공하지 않습니다.

    SRT 파일과 VTT 파일은 어떻게 다른가요?

    SRT는 쉼표로 밀리초를 구분하고 자막 번호를 사용하며, WebVTT는 마침표로 밀리초를 구분하고 WEBVTT 헤더를 사용합니다. 변환할 때 시간과 내용은 유지합니다.

    내 자막이 외부 서버에 저장되나요?

    아니요. 선택한 자막은 브라우저 안에서 처리합니다. 웹사이트 접속을 위한 일반적인 호스팅 요청 외에 자막 내용을 업로드하지 않습니다.

    변환 후 자막이 여전히 안 맞으면요?

    일정한 시간 차이는 초 이동으로 해결할 수 있지만, 영상 편집으로 부분마다 시간이 달라진 경우에는 구간별 수동 편집이 필요합니다. 이 도구는 일괄 조정만 제공합니다.

    이 도구는 파일을 서버로 전송하지 않습니다. 모든 편집은 현재 브라우저에서 실행되며, 페이지를 닫으면 편집 데이터가 사라집니다. 개인 콘텐츠는 원본을 따로 보관하세요.

    작업 결과는 참고용입니다. 중요한 자막은 원본을 백업하고 실제 영상과 다시 확인하세요.
